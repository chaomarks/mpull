# 登录背景（远程图库）

把图片（png / jpg / jpeg / webp / gif）或视频（mp4 / webm / ogv）放到本目录，
再把文件名登记到仓库根目录的 `login-bg.json`，MPull 的「设置 → 其他设置 → 登录背景 → 选择背景」
里就会出现缩略图，点击即可用作登录页背景。

- 不需要重新打包镜像；图库结果有 10 分钟缓存，弹窗里点「刷新」可立即看到新文件。
- `login-bg.json` 的 `files` 里可以直接写文件名，也可以写成 `{"file": "xxx.mp4", "name": "自定义标题"}`。
- 视频建议压到 5~10MB、1280×720 左右，登录页加载更快。
